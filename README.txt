词屿项目

当前源码：source/
电脑试玩：outputs/0.11/Windows/LittleTide.exe（双击运行，无需安装）
当前安卓包：outputs/0.11/Android/词屿-0.11.0.apk
开发特权默认开启：卡片双箭头跳过单题；设置 → 开发特权可“完成当前工地”或“全部建设完成”，再从“巡游与海底”定位船坞、群岛、望远镜、蓝鲸和洞窟。开发推进正常保存，学习记录不虚增；可在设置关闭。
当前只有一个正常应用入口，不再提供独立美术预览启动器。点学习卡外收起卡片，空白处显示时间。电脑与手机存档各自独立，不自动同步。
顶部书脊图标选择小学至专八六本参考词书；按隔两级规则剔除基础词，同词共享记录。词量决定建设小步的练习量，每次仍有可见进度。
设置 → 星空与星云：五个滑条实时调整；程序体积星云位于远景，不使用星云壁纸。每次启动随机，“换片星空”立即更换布局，用户参数自动保留。建好山顶观星台后，选择它并点卡片上的望远镜图标近看。
设置 → 人物 → 选择 VRM 模型：电脑和安卓均使用系统文件选择器，导入自己的本地人形模型。名称与作者显示在人物面板，重开后自动恢复，也可恢复白色人物。人物文件与配置单独保存，不改学习存档；导入失败保留原人物。Android 使用原生文档选择插件，不联网、不申请全盘存储权限。
本机已使用“蓝色小肥鱼Deepseek”（作者：木子恶魔）验证导入；该外部用户文件不随源码、Windows 程序或 APK 分发，也不计入项目的 73 套自制模型。支持范围见 source/README.txt。
玩法、构建依赖、脚本入口和检查边界见 source/README.txt。

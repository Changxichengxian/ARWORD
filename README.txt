ARWORD

当前版本 v0.12.0。Windows 个人试玩程序位于 outputs/0.12/Windows/ARWORD.exe。安卓个人首装包位于 outputs/0.12/Android/ARWORD-0.12.0.apk。公开版安装包和更新清单位于 GitHub Releases。
https://github.com/Changxichengxian/ARWORD/releases/latest

竖屏拖动小星球，点击工地打开练习。词卡按所选词书取词。阅读、听力和组句从全库轮换。建好远岛矿洞与主岛铸币坊，向背面的海怪分批交付金币，再以一本词书的首轮独立辨认记录解锁火箭。
在个人版的“设置 → 人物”可直接选择大肥鱼和默认人物。公开版可复用已由个人首装包保存的人物。安装后从“设置 → 检查更新”连接发布仓库，普通学习在本地运行。

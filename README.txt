ARWORD

当前源码版本为 v0.12.3。本版构建目标为 Windows 试玩程序 outputs/0.12.3/Windows/ARWORD.exe、安卓个人首装包 outputs/0.12.3/Android/ARWORD-0.12.3-setup.apk（版本代码 14），以及公开稳定包 outputs/0.12.3/Public/ARWORD-0.12.3.apk（版本代码 15）。已发布的公开版可在 GitHub Releases 下载。
https://github.com/Changxichengxian/ARWORD/releases/latest

竖屏拖动小星球，点击工地打开练习。词卡按所选词书取词。阅读、听力和组句从全库轮换。建好远岛矿洞与主岛铸币坊，向背面的海怪分批交付金币，再以一本词书的首轮独立辨认记录解锁火箭。
双指拖移、旋转、张合可以在一个动作中完成。火箭岛的深水中伸出四条触手，抓住岛岸和火箭。交满 36 枚金币后，触手松开泊位，远海仍露出一段弧背。
先打开个人首装版一次，让它保存大肥鱼，再从“设置 → 检查更新”选择升级，即可通过差异文件进入公开稳定版并继续使用已保存的人物。手机优先从 GitHub Releases 官方 API 读取版本信息和下载附件，网页路径作为备用。确认下载量后由安卓系统提示安装。普通学习在本地运行。

点工地会立即起身跑向可到达的落脚点，有船坞时可以跨岛。移动不发材料、不计学习。选中工地的白色虚线在一张与地表相切的平面上悬浮，只有切换地点或扩地才重算高度。火箭岛的一臂沿岛缘回抱，另一臂绕箭身向上盘旋。安卓水面用真实海床深度和透明混合，天空与星球分开控制绘制开销。

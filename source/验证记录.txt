增量更新
设置中手动检查公开 GitHub Releases。客户端按当前 APK 的完整哈希选择差异，显示实际下载量。收到文件后逐字节复原签名 APK，检查文件大小、完整哈希、新包名、更高版本与签名，再交给安卓系统确认安装。匹配不到差异时显示完整包下载量。安装包与差异附件存放在发布区，Git 只保存源码与源资产。
签名测试样包验证了较高版本的差异生成与还原、拒绝旧包名及同版本号。安卓 Java 还原代码通过真实大文件重建，并拒绝损坏数据。用两版实际游戏文件比较传输量，179,130,873 字节的公开目标有 162,449,189 字节可复用，差异文件 13,167,915 字节，可精确还原。旧词屿与新 ARWORD 包名不同，该数据仅为字节复用测试。首个公开更新清单没有差异起点。
本次正式同版本覆盖使用设备测试工具。正式发布的更高版本经差异下载、系统弹窗和升级的一整次过程，需等有适用的下一次发布才能验证。

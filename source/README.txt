词屿 · 0.9.0 竖屏小星球样段

电脑上直接看
交付目录 Windows/LittleTide.exe 双击运行，无需安装 Godot、模拟器或浏览器。仍是同一个原生 3D 场景和学习流程。Windows 10/11 x64，需要 Vulkan 显卡支持；窗口按屏幕可用高度缩放为竖屏。
鼠标左键拖动星球，滚轮缩放，点建筑或悬浮进度条打开工地学习卡；点卡片外收起。卡片滑出并淡出，镜头小幅后退约 12%，不突然跳远。词卡收起时，星球与宇宙之间显示本机时间。
本版只有正常应用入口，不再生成“直接看美术”启动器，也不显示预览说明、预设星球名或“继续照料”按钮。电脑正常存档保存在 Windows 本机，不自动同步手机。
开发特权默认开启，方便在正常应用里检查后续建设。学习卡的双箭头跳过当前练习，直接推进一次采集或建设并播放工作动作。可在设置中关闭；跳过后的世界进度正常保存，退出重开仍在。
道路只保留少数建筑与加工点附近的短路，不再连遍所有六边形地块。小人按实际移动距离迈步，区分走路、轻跑和搬运；干活时腰、膝、肩肘共同参与蓄力、下击和回弹。低洼浅湾、草坡、高原和山地继续使用实际高度。

独立 Android 应用，包名 com.wordfrontier.planet。Godot 4.5.1 实时三维渲染；离线运行，无浏览器或 WebView。需要 Android 7.0 以上及 Vulkan 支持。与 0.4 / 0.5 同包升级，继续读取原存档；0.2、0.3 是不同应用。

这一段怎么玩
从飞船旁的三块小陆地开始。上半屏拖动看四周，点建筑或物体上方的进度条，选择这一段要做的事。只有选中的地方有白色虚线圈，缓慢旋转并呼吸明暗；没有固定的三个建筑按钮，也没有操纵杆。
先接出树林或石岸，然后陆续打开锯木坊、草地、砖窑、晶簇小湾和向风小丘。十段扩地共 78 步，将 3 块陆地接成 33 块；通常每两到四步就有一块新地面。正常练习和开发跳过都能推进建设，每段有固定终点，不继续增加等级或扩地账单。
木屋、风车、花园及原来的九项后续建设仍保留。木屋在起点，风车和花园随相应土地出现；旧存档已经获得的建筑和附属设施直接保留。建筑主体和附属工程共 144 步，加上新扩地全流程共 222 步。完成后可以继续学习和照料，世界进度不无限增加。
每个工地独立记录进度。六次工作包含三次词义回忆、一次阅读、一次听力、一次句子组织。选词、读懂安排、听指令和组织句子都直接推动所选工地；材料会在世界内移动，没有领木头页面或背包兑换。锯木坊和砖窑完成后，相应采集材料经过加工点，变为木板或砖块，再送往工地。
每次正确词义回忆增加 12 秒工作；阅读、听力、组句各增加 9 秒，最多积到 36 秒。换下一题不会打断这段工作。人物走向采集点、搬运、敲打建设；工作时间结束后收起工具，坐下、躺着、伸懒腰或轻晃脚。开发跳过同样触发当前工序的工作动作。额外动作和休息均不追加资源、建设或学习记录，工作时间只在本次运行中播放，不积累离线收益。没有角色或工具数值升级。
新地形使用累计记录解锁：完成南边草地且木料采集累计 8 次，可接芦苇浅湾；完成石岸且石料采集累计 10 次，可接石脊高原；完成高原、小丘且阅读加听力累计 12 次，可接云杉山地。达到前置条件后先显示灰色预告和累计进度，点它可看所需条件。达标后可以选择扩建，不会直接送出全部土地。原有累计记录继续有效。
开发跳过词卡会计入场景采集；跳过阅读或听力会写入独立的开发推进计数，并参与对应地形的开放条件。这些操作不改变词汇记忆强度、不增加学习统计里的阅读/听力/组句完成数，也不清除尚未独立完成的提示记录。
看不懂时可以看释义、译文或听力原文，再继续。提示记录保留，不扣体力、不倒计时。答错和使用提示后的练习，不标成独立掌握。

操作
上下左右拖动星球，表面跟着手指移动；双指张开拉近、合拢拉远。指南针回到当前工地。闭卡时点建筑或悬浮进度条切换目标并打开卡片；开卡时点外部先收起。进度跟随对应物体的位置和高度，转到星球背面或卡片后隐藏；白色旋转环只属于当前选中的一个目标。
云朝向球心并随球转动，船头沿航向。人物有肩肘、腿膝和工具动作，树木、矿物和新陆地以短促回弹出现。
点单词即发音；阅读中的词可点开释义并自动发音。空心星星未收藏，实心星星已收藏。没有额外的“音”按钮和音标。
顶部耳机在词卡上切换听音辨义，在阅读或听力任务中重播。书本打开当前工作手记，齿轮里调整词汇起点、自动读词、音效、轻音乐和开发特权，也可查看收藏。
阅读可选短版或展开版；长文仅在阅读区域内滚动。听力可重播、慢放或看原文。句子词块保持固定位置，选过的变灰。

可以停下来看什么
宇宙保留大面积深黑暗处，银河以蓝紫、青绿和少量暖粉自然混合，有黑色尘带、疏密不同的星群和缓慢漂移的局部星云。太阳与四颗风格不同的行星在独立的透视三维空间中公转、自转；轨道和距离经过压缩，便于在手机上看清远近变化。当前这些星体只供观察和轻触反馈，不能登陆、旅行或建设。
岛上有鸟和蝴蝶，海里有鱼群与鲸。海床包含浅滩与深盆地，海水有波动、岸边浪纹和局部涟漪；水生动物使用同一份水面和海底高度判断活动位置。小动物只提供观察与轻触响应，不代替学习、不产生建设收益。
设置中的“星空与星云”提供五项实时滑条：星云浓度、色彩强度、银河宽度、星星密度和漂移速度。面板放在下方，上方天空不遮暗，拖动立即生效；松手、关闭或退出时保存，也可恢复默认。漂移调为零只停住星云，行星继续运行；调速不跳相位。
背景音乐为本项目原创的 Island Drift，80 秒器乐循环。播放单词或听力语音时自动压低，结束后逐渐恢复；轻音乐与操作音效可以分别关闭。

内容与学习范围
96 个精选词，四档粗略难度；17 组原创工作手记，每组有短文、展开阅读、听力指令和句子组织。同组重点词会在各项工作中重现。短文约 27–35 词，展开阅读约 52–65 词；基础/适中默认短版，进阶/挑战默认展开版。
默认从第二档开始，连续独立答对四次上调，连续两次需要提示下调，也可手动改起点。这不是总词汇量测试，四选一不能证明自由回忆能力。
提示后的词约两分钟进入复习；首次独立回忆也约两分钟再见，之后逐步延长到十分钟、数小时和数天。即时重复不增加记忆强度。阅读、听力、组句分别记录完成和是否看过提示，不据此虚增词汇掌握量。
当前流程使用 668 段离线语音：96 个重点词、51 段短文/展开文/指令、521 个查词词形。词典包含 617 个词形。语音使用 Kokoro af_heart 合成，非真人录音；慢放尽量保持音高。源码另保留三段旧版来信语音。
这仍然是有限内容的样段，没有在线生成、无限词库、跨星球旅行或自由建造。扩地路线与建筑位置由地图预先安排，玩家选择当前可用工地；学习与施工仍有抽象对应。构建、截图和流程检查不能证明好玩、实体手机流畅或学习有效。

存档
user://island4.json，临时文件写完后替换，另留 .bak。保留原有建筑、词汇、收藏、难度和安排；0.6 使用可选 frontier 字段保存扩地区域、当前工地和独立工作轮次；已有词汇、收藏、三处建筑和工作轮次保留。旧建筑所需的支撑陆地直接出现，不拆旧建筑、不重做旧学习记录。旧版已建成的主体不重做，不清空旧词汇。卸载或清除应用数据会删除存档。
0.9 增加可选的 music、dev_skip、dev_steps、dev_context 字段。旧存档缺少这些字段时使用默认值；开发跳过采用正常存档，不是退出就清空的体验模式。--qa 和内部预置场景仍使用隔离记录，仅供自动检查。
space_settings 保存星空五项参数；缺项使用默认值，非法数值恢复默认或限制到滑条范围，不改变学习和施工记录。

源码与美术
scripts/main.gd：流程、音频、存档、阅读与句子组织。
scripts/learning.gd：复习、难度、建筑进度。
scripts/frontier.gd：有限地图、解锁条件、分工地进度和兼容读取。
scripts/grove.gd：三维场景、采集、搬运、建筑动画。
scripts/terrain.gd：共享的六边形地表高度、相连边界与地形类型。
scripts/worker.gd：有时限的工作与休息动作，不修改学习记录。
scripts/water.gd、assets/water.gdshader、shore_foam.gdshader：海床深度、海水和岸边浪纹。
scripts/wildlife.gd：鸟蝶、鱼群、鲸与水面互动。
scripts/cosmos.gd、assets/cosmos_*.gdshader：透视太阳系与动态深空背景。
scripts/ambience.gd：背景音乐、语音时压低音乐和退出释放。
scripts/hud.gd、icon_button.gd：原生游戏界面和图标。
assets/vocabulary.json、missions.json、frontier_missions.json：教学内容；改英文语音文字后需重新生成对应录音。
art-source：39 个原创 Blender 源文件。assets/models：对应 GLB 运行资源。它们是源资产，保存在 Git；远景星体与星空另由程序网格和着色器生成，相关源码一并保存。
tools/make_art.py、render_icon.py：Blender 4.4.3 后台运行，生成模型和图标。
tools/make_life_art.py：生成鸟、蝴蝶、鱼和鲸的 Blender 源文件与运行模型。
tools/make_music.py：原创器乐循环的音符、音色与合成过程；运行需要 numpy、soundfile 及 FFmpeg。
tools/make_missions.py：生成 12 组建筑手记。tools/make_frontier_missions.py：生成 5 组扩地与加工手记。
tools/make_dictionary.py：传入 ECDICT CSV 路径，提取词形和释义。
tools/make_audio_manifest.py：从当前词库、手记、词典生成语音清单。
tools/make_voice.py：--models 指向 Kokoro ONNX 模型目录，--ffmpeg 指向 FFmpeg；依赖 kokoro-onnx、onnxruntime、numpy、soundfile。按文字哈希增量生成，模型不随源码保存。
tools/make_font.py：Python fonttools，生成静态字体子集，文字改动后运行。
第三方许可见 assets/CREDITS.txt。

构建
Windows：Python 调用 build_desktop.py --godot <Godot控制台exe> --templates <4.5.1 templates.tpz> --output <交付目录>。使用独立编辑器配置和临时目录，导出内嵌资源的单个 EXE 与来源哈希，不再生成公共美术预览启动器。无需签名资料。交付程序不含测试代码、Blender 工程或浏览器。
Android：依赖 Godot 4.5.1 及对应 Android 导出模板、Android SDK、JDK 21。PowerShell 7 调用 build.ps1，传入 -Godot、-Templates、-AndroidSdk、-JavaHome、-SigningProperties、-OutputDirectory。签名配置属于私密文件，勿提交 Git。
脚本在独立临时目录导入和导出，不修改全局 Godot 设置；对齐、签名、验证后清理本次中间目录。生成 APK、SHA256SUMS.txt、source-inputs-sha256.json 和 build.log。输入清单用于核对交付来源。
当前主场景用 FXAA 抗锯齿，关闭 MSAA：Godot 4.5.1 的 Mobile 渲染在 MSAA 开启时会让海水深度纹理失效。海水颜色、吸收和轻微折射读取实际海床及水下模型深度；海床几何和动物深度限制共享测深数据。不要为消除边缘锯齿而直接重新开启主场景 MSAA。

版本保存
唯一工作源码在 source/。根目录 Git 用 v0.1.0 至 v0.9.0 保存各代源码。用 git archive 导出旧版到独立目录，不直接覆盖当前工作源码。EXE、APK、测试包、缓存和签名资料不提交 Git。新版验证后只保留当前 Windows 试玩和 APK；旧版源码继续由 Git 保留。

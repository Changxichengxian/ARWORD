词屿 · 0.5.0 竖屏小星球样段

独立 Android 应用，包名 com.wordfrontier.planet。Godot 4.5.1 实时三维渲染；离线运行，无浏览器或 WebView。需要 Android 7.0 以上及 Vulkan 支持。与 0.4 同包升级，继续读取原存档；0.2、0.3 是不同应用。

这一段怎么玩
木屋、风车、花园可以随时选。点底部三处地点，或点画面里的建筑。每处的工作分别推进，不强制按顺序解锁。
六次工作中有三次词义回忆、一次阅读、一次听力、一次句子组织。词义回忆直接采集眼前资源；读工作手记后在建筑旁修整，听懂安排后搬运材料，组织句子后继续建设。材料与光点直接进入当前地点，没有领奖、仓库兑换或战斗结算。
主体分别需要 8、12、16 次工作，再各增加三个 12 步的小项目。木屋增加栈道、长椅、营地；风车增加水箱、水渠、工作台；花园增加果树、栅栏、蜂箱。全部共 144 次有效操作，有明确终点；之后仍可照料和复习，不增加无穷等级。
看不懂时可以看释义、译文或听力原文，再继续。提示记录保留，不扣体力、不倒计时。答错和使用提示后的练习，不标成独立掌握。

操作
上半屏上下左右拖动星球；指南针图标回正，星球图标收起学习卡片。云朝向球心并随星球转动；船沿航线朝前，人物走路、挥工具，资源和建筑出现时有短促回弹动画。
点单词即发音；阅读里的词可点开释义并自动发音。空心星星是未收藏，实心星星是已收藏。没有额外的“音”按钮，也没有自动音节拆分。
顶部耳机在词卡上切换听音辨义，在阅读或听力任务中重播。书本打开当前工作手记。齿轮里可调整词汇起点、自动读词、音效和查看收藏。
阅读可选短版或展开版；长文只在阅读区域内滚动。听力可重播、慢放或看原文。句子词块保持固定位置，选过的变灰。

内容与学习范围
96 个精选词，四档粗略难度；12 组原创工作手记，每组有短文、展开阅读、听力指令和句子组织。同组重点词会在各项工作中重现。短文 27–34 词，展开阅读 52–61 词；基础/适中默认短版，进阶/挑战默认展开版。
默认从第二档开始，连续独立答对四次上调，连续两次需要提示下调，也可手动改起点。这不是总词汇量测试，四选一不能证明自由回忆能力。
提示后的词约两分钟进入复习；首次独立回忆也约两分钟再见，之后逐步延长到十分钟、数小时和数天。即时重复不增加记忆强度。阅读、听力、组句分别记录完成和是否看过提示，不据此虚增词汇掌握量。
当前流程使用 607 段离线语音：96 个重点词、36 段短文/展开文/指令、475 个查词词形。语音使用 Kokoro af_heart 合成，非真人录音；慢放尽量保持音高。源码中保留三段旧版来信作为历史资源。
有限内容的样段，没有在线生成或无限星球。自由选择目前限于三个工作地点及读/听/查词等操作；并非开放世界。学习题与建设仍有抽象对应，是否有趣、能否长期复玩，要看真实试玩。

存档
user://island4.json，临时文件写完后替换，另留 .bak。保留原有建筑、词汇、收藏、难度和安排；0.5 在原数据上添加分地点进度和阅读/听力/组句记录。旧版已建成的主体不重做，不清空旧词汇。卸载或清除应用数据会删除存档。

源码与美术
scripts/main.gd：流程、音频、存档、阅读与句子组织。
scripts/learning.gd：复习、难度、分地点进度。
scripts/grove.gd：三维场景、动作、采集、搬运、建筑动画。
scripts/hud.gd、icon_button.gd：原生游戏界面和图标。
assets/vocabulary.json、missions.json：教学内容；改英文语音文字后需重新生成对应录音。
art-source：20 个原创 Blender 源文件。assets/models：对应 GLB 运行资源。它们是源资产，保存在 Git。
tools/make_art.py、render_icon.py：Blender 4.4.3 后台运行，生成模型和图标。
tools/make_missions.py：生成 12 组精选工作手记。
tools/make_dictionary.py：传入 ECDICT CSV 路径，提取词形和释义。
tools/make_audio_manifest.py：从当前词库、手记、词典生成语音清单。
tools/make_voice.py：--models 指向 Kokoro ONNX 模型目录，--ffmpeg 指向 FFmpeg；依赖 kokoro-onnx、onnxruntime、numpy、soundfile。按文字哈希增量生成，模型不随源码保存。
tools/make_font.py：Python fonttools，生成静态字体子集，文字改动后运行。
第三方许可见 assets/CREDITS.txt。

构建
依赖 Godot 4.5.1 及对应 Android 导出模板、Android SDK、JDK 21。PowerShell 调用 build.ps1，传入 -Godot、-Templates、-AndroidSdk、-JavaHome、-SigningProperties、-OutputDirectory。签名配置属于私密文件，勿提交 Git。
脚本在独立临时目录导入和导出，不修改全局 Godot 设置；对齐、签名、验证后清理本次中间目录。生成 APK、SHA256SUMS.txt、source-inputs-sha256.json 和 build.log。输入清单用于核对交付来源。

检查
Godot --headless --editor --path . --import
Godot --headless --path . --script tests/core.gd -- --qa
python tools/check_assets.py
--qa 隔离测试存档；常规应用不会启用。tests/android 是独立的 Android 触控检查程序，不包含在游戏 APK 中。预置的完工场景只用于画面与存档检查，不代表真实学习完成。
具体检查结果见 验证记录.txt。构建、流程检查和截图不能证明实体手机流畅、愿意复玩或学习有效。

版本保存
唯一工作源码在 source/。根目录 Git 用 v0.1.0 至 v0.5.0 保存各代源码。用 git archive 导出旧版到独立目录，不直接覆盖当前工作源码。APK、测试包、缓存和签名资料不提交 Git。新版验证后只保留当前试玩 APK；旧版源码继续由 Git 保留。

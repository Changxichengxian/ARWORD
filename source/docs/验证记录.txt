词境前线 0.1.0｜验证记录
2026-10-12

已经验证

1. 原生 Android 安装与运行
最终个人签名 APK 已安装到 Android 16.1 模拟器；首次启动、离线词典、来访录音、选择奖励和建设经过实际界面操作。应用使用 Android 原生控件和 Canvas，没有 WebView 引用，没有 HTML 页面运行环境。
模拟器中的实际安装名为 com.wordfrontier.app。安装包没有声明网络、麦克风、联系人或广泛存储权限；发布包不启用调试。独立个人签名通过 Android APK 签名验证。
从模拟器读回实际安装的 base.apk，与交付 APK 的 SHA-256 完全相同，确认验证对象就是这份安装文件。

2. 最终发布包上的完整流程
使用与发布包相同证书签署测试包，在发布版应用上执行，458 项原生检查通过。检查项包含循环中的断言，并不等于 458 个不同场景。
覆盖：16 题初始抽样、自报猜测、分别安排技能起点；离线原速/慢速播放、字幕帮助、媒体资源释放；单词读音和四种反馈音资源；立即缩短阅读而不改变对手动作；完整组句及预设合理变体；错误存档拒绝；减少动画；阅读、选战术、出手、结算、下一回合、整场奖励；暂停和继续；四座建筑永久完成、收获；来信阅读记录；真实原生文章输入框保留 200 词全文、标题限长；来访奖励不重复且不增加答题正确数；词汇档案翻页。

3. 存档与界面
通过 Android 系统文件选择器实际导出 JSON，再导入测试存档，观察建设/材料变化并撤销；不支持的存档版本被拒绝且保持当前进度。
强制停止后重新打开，未结束交锋的题目、对手预先选择和反馈状态得以保留。对发布包进行同签名覆盖安装后，进行到一半的交锋仍可继续。
已有检查覆盖 320 dp 宽度、字体放大到 1.3 倍和横屏；主要战斗操作可以滚动完成，旋转不重掷对手动作。普通尺寸截图来自实际原生应用画面。
额外在发布包上检查 320 dp 宽度、1.5 倍字体：难度对话框可操作；短文输入框随键盘收缩，保存/取消保持可见；实际输入并保存标题及 12 词全文，重新打开内容一致。模拟器尺寸、密度、字体和旋转设置已恢复到测试前的值。

4. 规则与内容
纯 Java 规则测试通过 18,070 次断言，包含 6,000 场固定种子对战模拟。独立读懂、稳定出手、标准压力、常规配装条件下：
  利用情报并考虑体力：2,000 场，胜 1,738，平 134。
  随机选一种动作，体力不足则固守：2,000 场，胜 1,059，平 197。
  反复突击，体力不足则固守：2,000 场，胜 760，平 329。
模拟用来检查行动信息有用、体力受约束、奖励不重复等规则，不是对真实玩家胜率或“好玩”的预测。对手不会读取本回合玩家输入，也没有强制胜负交替机制。

内容包含 244 道练习、24 版来信、8 版来访。唯一编号、选项、答案索引、组句词块、词典数据库均通过自动检查。216 段 MP3 全部可以解码，无缺失或静音异常，总原录音时长约 1,754.6 秒。录音清单与英文正文一致。正文所需词形在内置词典中均可查到。
题干、译文和选项经过逐类复读；词义干扰项按例句中的词性分组，避开部分容易同时成立的近义译法。材料没有经过大样本难度校准，机器检查也不能保证每道题都完全没有歧义。

5. 构建与交付
JDK 21、Gradle 8.9、Android Gradle Plugin 8.6.1、SDK 36 / Build Tools 34.0.0 构建成功。最低系统声明 API 26，目标 API 35。
Android Lint 为 0 个错误、8 个警告：4 处小存档同步写入，1 处目标系统版本提示，2 处只由代码创建的自定义控件构造器提示，1 处中文播放状态拼接提示。没有用基线文件隐藏错误。
源码包包含构建工具入口、应用源文件、词典、录音、内容生成工具和测试；排除本机路径、缓存、构建结果和个人签名口令。签名单独交付，不放进普通源码包。
源码解压到全新目录，恢复单独的个人签名后独立构建成功；两个 APK 内的 230 个文件内容逐项相同，签名证书一致。容器层字节和 APK 整体哈希不同。
在新目录运行 --reuse-dictionary，生成的 content.json、音频清单及词典数据库与随包文件哈希一致，不需要原始大词典 CSV。
附带约 89 秒无声操作预览，来自模拟器屏幕录制；安装包内的学习录音仍可正常播放。它展示复看英文、选择战术、出手和结果，未用网页或概念图替代应用界面。

尚未验证

没有在你的真实手机上安装或试听，未实际运行 Android 8.0 等其他系统版本。没有长期耗电、低端机性能、屏幕阅读器完整适配的实机数据。
离线录音经过解码和 Android 播放检查；这不等于真人对全部发音、自然度和听感的逐段评审。
词汇抽样不等于标准化词汇量测验。难度调整和间隔规则是可修改的原型方案，尚无长期学习效果数据。
本地对手和回合制不能证明能满足你偏好的真人即时对抗体验。真正的吸引力、学习负担和继续玩的意愿需要你试玩判断。

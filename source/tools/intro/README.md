# 录制 ARWORD 介绍视频

在这台 Windows 电脑上，双击同目录的「录制介绍视频.cmd」。完成后打开项目里的 `outputs/应用介绍/ARWORD-介绍.mp4`。默认录成 720 × 1280、每秒 24 帧的竖屏视频。只有成片通过完整解码检查，工具才会替换上次的文件。

旁白和每个镜头停留多久，都在 `story.json`。改 `line` 就能换台词，`at` 是开口前留的秒数。台词变长时，镜头会自动延长。开头、蝴蝶和结尾黑洞的镜头留给音乐。用 `--width 1080 --fps 30` 可以重录成更高分辨率，`--output` 可以另存一份。

工具直接拍摄 Godot 里的应用。词卡用小学词书里的 island（岛）演示认词与回忆，中间播放个人声包里这条词的英语发音。换示例词时，一起改词卡镜头的 `book` 和 `word`。扩地镜头把中间多次练习压缩到同一个机位。后期的海岸和观星台使用单独的演示进度。拍摄期间，游戏使用临时目录和隔离存档。

中文旁白先由 Windows 普通话语音朗读，再使用个人声包的 OpenVoice V2 模型和 `cute_N01.wav` 转成大肥鱼音色。语音素材来自星落落_oi 授权训练的社区声库，由 Esmerubphire 发布。大肥鱼形象作者为木子恶魔。成片和临时素材都保存在本机。

换电脑时，需准备 Godot 4.5.1、带字幕渲染功能的 FFmpeg、Windows 普通话语音、项目的个人角色和音色文件，并先用 Godot 导入 `source/`。默认沿用本项目 Ubuntu 子系统中的音色转换环境。可用 `--voice-python` 指定装有相同依赖、能使用 NVIDIA 显卡的 Windows Python。运行 `python record.py --help` 可查看工具、参考音和模型路径选项。
